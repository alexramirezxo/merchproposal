# Make it MERCH — propuesta de diseño

Sitio estático rediseñado tomando como referencia la composición editorial del PDF suministrado: navegación lateral compacta, mucho espacio en blanco, divisores finos, secciones numeradas, composición editorial limpia, divisores puntuales y una paleta blanca, negra y azul.

## Archivos

- `index.html` — estructura completa y contenido de la propuesta.
- `styles.css` — sistema visual, responsive y estilos inspirados en la referencia.
- `script.js` — estado activo del índice lateral durante el scroll.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html`, `styles.css`, `script.js` y este `README.md` a la raíz.
3. En GitHub abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main` y la carpeta `/ (root)`.
6. Guarda los cambios y espera a que GitHub Pages publique la URL.
