# Propuesta de diseño de merch

Sitio estático listo para publicar en GitHub Pages.

## Archivos

- `index.html` — estructura y contenido de la propuesta.
- `styles.css` — sistema visual y comportamiento responsive.
- `script.js` — navegación lateral activa durante el scroll.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html`, `styles.css` y `script.js` a la raíz del repositorio.
3. En GitHub ve a **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda. GitHub mostrará la URL pública del sitio.
